# Implementation contract (shared by all agents)

Read together with `docs/PLAN.md`. Base package `com.example.app`. No Lombok — plain getters/setters.
Every agent codes against exactly these names. If you need something not listed, add it inside your own files only and mention it in your report.

## Entities + repositories (DB agent)

All timestamps are `java.time.Instant`, SQL type `TIMESTAMP WITH TIME ZONE`. IDs `Long`, `BIGINT GENERATED BY DEFAULT AS IDENTITY`, `@GeneratedValue(strategy = IDENTITY)`.
Every entity: `protected` no-arg ctor for JPA, the public ctor listed, getters for every field.

| Class | Table | Fields → columns | Public ctor / mutators |
|---|---|---|---|
| `user.User` | `users` | id, username, passwordHash→password_hash, createdAt | `User(String username, String passwordHash)` sets createdAt=now |
| `auth.AuthToken` | `auth_token` | id, `User user` (ManyToOne LAZY, user_id), tokenHash→token_hash, createdAt, expiresAt | `AuthToken(User user, String tokenHash, Instant expiresAt)` |
| `poll.PollStatus` | — | enum `OPEN, CLOSED` | |
| `poll.Poll` | `poll` | id, shareId→share_id, `User creator` (ManyToOne LAZY, creator_id), question, `PollStatus status` (@Enumerated STRING), `@Version Long version`, createdAt, updatedAt, `List<PollOption> options` (@OneToMany mappedBy="poll", cascade PERSIST+MERGE, **no** orphanRemoval, @OrderBy("position")) | `Poll(User creator, String shareId, String question)` sets status=OPEN, createdAt=updatedAt=now; `setQuestion(String)`, `touch()` (updatedAt=now), `PollOption addOption(String text, int position)` |
| `poll.PollOption` | `poll_option` | id, `Poll poll` (ManyToOne LAZY, poll_id), text→option_text, position, voteCount→vote_count (int) | `PollOption(Poll poll, String text, int position)`; `setText`, `setPosition` |
| `vote.Vote` | `vote` | id, `Poll poll`, `User user`, `PollOption option` (all ManyToOne LAZY; poll_id, user_id, option_id), createdAt, updatedAt | `Vote(Poll poll, User user, PollOption option)`; `changeOption(PollOption)` (also updatedAt=now) |
| `audit.AuditAction` | — | enum `USER_REGISTERED, POLL_CREATED, POLL_UPDATED, VOTE_CAST, VOTE_CHANGED` | |
| `audit.AuditEvent` | `audit_event` | id, `Long actorId`→actor_id (plain column, nullable), `AuditAction action` (STRING), `Long pollId`→poll_id (nullable), details, createdAt | `AuditEvent(Long actorId, AuditAction action, Long pollId, String details)` |

Repositories (all `extends JpaRepository<Entity, Long>`):

```java
// user.UserRepository
Optional<User> findByUsername(String username);
boolean existsByUsername(String username);

// auth.AuthTokenRepository
@EntityGraph(attributePaths = "user") Optional<AuthToken> findByTokenHash(String tokenHash);

// poll.PollRepository
Optional<Poll> findByShareId(String shareId);
boolean existsByShareId(String shareId);
List<Poll> findByCreatorIdOrderByCreatedAtDesc(Long creatorId);

// poll.PollOptionRepository  — all @Modifying(clearAutomatically = true, flushAutomatically = true), return rows affected
int incrementVoteCount(Long pollId, Long optionId);   // set voteCount = voteCount + 1 where id=:optionId and poll.id=:pollId
int decrementVoteCount(Long pollId, Long optionId);   // ... - 1 where ... and voteCount > 0
int deleteIfNoVotes(Long pollId, Long optionId);      // delete where id=:optionId and poll.id=:pollId and voteCount = 0
List<PollOption> findByPollIdOrderByPosition(Long pollId);

// vote.VoteRepository
Optional<Vote> findByUserIdAndPollId(Long userId, Long pollId);
@Lock(PESSIMISTIC_WRITE) @Query("select v from Vote v where v.user.id = :userId and v.poll.id = :pollId")
Optional<Vote> findForUpdate(Long userId, Long pollId);
long countByOptionId(Long optionId);
long countByPollId(Long pollId);

// audit.AuditEventRepository
List<AuditEvent> findByPollIdOrderByIdAsc(Long pollId);
List<AuditEvent> findByActorIdOrderByIdAsc(Long actorId);
```

**Persistence-context rule:** the bulk `@Modifying` queries clear the persistence context. Services must run them *before* loading entities they intend to modify, or re-fetch afterwards.

## Backend (Backend agent)

- `auth.CurrentUser` — `record CurrentUser(Long id, String username)`; it is the Spring Security principal. Controllers take `@AuthenticationPrincipal CurrentUser me`.
- `web.ApiException extends RuntimeException` — `ApiException(HttpStatus status, String message)`; `web.ApiExceptionHandler` (@RestControllerAdvice) maps it, bean-validation errors (400 + fieldErrors), `ObjectOptimisticLockingFailureException` (409), `DataIntegrityViolationException` (409) to
  `{"status":409,"error":"Conflict","message":"...","fieldErrors":[{"field":"question","message":"..."}]}` (`fieldErrors` only on 400).
- Unauthenticated `/api/**` → 401 with the same JSON shape (security entry point). Forbidden → 403.
- DTOs are Java records in each feature's `dto` package. JSON field names exactly as PLAN.md §5:
  - `auth.dto.RegistrationDto{username,password}`, `auth.dto.LoginDto{username,password}`, `auth.dto.AuthResponse{token,userId,username}`
  - `poll.dto.CreatePollDto{question, List<String> options}`, `poll.dto.EditPollDto{question, Long version, List<EditOptionDto> options}`, `poll.dto.EditOptionDto{Long id, String text}`
  - `poll.dto.PollResponse{id, shareId, question, status, version, creatorUsername, createdAt, updatedAt, totalVotes, List<OptionResponse> options}`, `poll.dto.OptionResponse{optionId, text, voteCount}`
  - `vote.dto.VoteRequest{Long optionId}`, `vote.dto.VoteResponse{pollId, optionId, updatedAt}`
- Services: `auth.AuthService`, `poll.PollService`, `vote.VoteService`, `audit.AuditService.record(Long actorId, AuditAction action, Long pollId, String details)` (`Propagation.MANDATORY`).
- Usernames are trimmed + lower-cased on register and login.
- Option lookups: an `optionId` that isn't in this poll → 404 "Option not found in this poll"; increment affecting 0 rows → 409 "Option no longer exists".

## Security permit list (Backend agent; UI relies on it)

Public: `/`, `/login`, `/register`, `/polls/new`, `/polls/*/edit`, `/p/**`, `/css/**`, `/js/**`, `/vendor/**`, `/app.css`, `/favicon.ico`, `/error`, `/h2-console/**`, `POST /api/v1/auth/**`, `GET /api/v1/polls/share/**`.
Everything else under `/api/**` requires the bearer token. Stateless sessions, CSRF disabled, no form login / basic auth, frame-options sameOrigin (H2 console).
Pages are public shells; the JS redirects to `/login?next=<path>` when it has no token or gets a 401.
